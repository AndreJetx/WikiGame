Contact Legend of Elements Wiki

Legend of Elements Wiki is a community-run fan wiki. There is no official publisher helpdesk, telephone number, or mailing address for this site. For questions about articles, missing pages, or the public API, open a GitHub issue on the project repository: github.com/AndreJetx/WikiGame.

Use GitHub when you want to report a factual error, request a category, flag broken API behavior, or discuss the agent-facing files (OpenAPI, llms.txt, MCP). Do not send account recovery, payment, or in-game support requests here — those belong with the game operator.

This contact page exists so players and agents can verify that the wiki is a real, maintained community project and know where to write. We do not collect inbound email on this domain and we do not operate a CRM. Response times depend on volunteer availability.

Public channels

Preferred channel: GitHub issues. Homepage: Legend of Elements Wiki. API documentation: /docs.
